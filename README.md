# Centro de Formación

Práctica de Aplicaciones Web — Daniel Maksymiv y Guillermo Patiño.

## Estructura

- Raíz del proyecto: frontend (HTML, CSS y JavaScript del navegador).
- `backend/`: código del servidor con Node.js.

## Backend

### Requisitos

Node.js en versión LTS, que incluye npm. Para comprobar la instalación:

```
node --version
npm --version
```

### Instalación de dependencias

```
cd backend
npm install
```

### Ejecución

```
npm start
```

También se puede ejecutar con `node app.js`, o filtrar cursos por nombre con `node app.js ingl`.
En desarrollo, `npm run dev` reinicia el programa automáticamente al guardar cambios.
